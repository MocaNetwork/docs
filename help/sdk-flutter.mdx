## Installation and OnePub

| Issue | What to try |
|-------|-------------|
| `onepub` command not found | Add `$HOME/.pub-cache/bin` to PATH |
| Package resolve failures | `onepub login`, verify hosted URL and version in [Flutter installation](/get-started/sdks/flutter/installation) |

## Android

| Issue | What to try |
|-------|-------------|
| Passkey / asset links | [Android setup](/get-started/sdks/flutter/android-setup): `strings.xml`, manifest `meta-data`, signing cert allowlisting |
| `minSdk` / manifest merge errors | Set `minSdk` 26+, `compileSdk` 34+ |

## iOS

| Issue | What to try |
|-------|-------------|
| Associated Domains | [iOS setup](/get-started/sdks/flutter/ios-setup): capability, exact domain entries, physical device |
| CocoaPods | `cd ios && rm -rf Pods Podfile.lock && pod install` |

## Runtime

| Issue | What to try |
|-------|-------------|
| Login UI does not appear | `navigatorKey` passed to `MaterialApp` and `initialize()` |
| `Service is not initialized` | Await `initialize()` before other calls |
| WebView blank | Platform network config, ATS (iOS), Associated Domains / asset links |

## Credentials on Flutter

Credential **issuance** and **verification** are available on Flutter. Use the [Issue credentials](/get-started/quickstarts/issue-credentials) and [Verify credentials](/get-started/quickstarts/verify-credentials) quickstarts, plus [Issuing credentials](/products/identity/issuing-credentials) and [Verify](/products/identity/verify).

If calls fail or payloads are rejected, see [Identity & Credential](/help/identity-credential). For Google OAuth client IDs and dashboard-side setup, see [Google Sign-In — Dashboard](/get-started/sdks/flutter/google-signin#dashboard).
