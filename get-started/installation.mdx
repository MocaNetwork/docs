## Install

<Info>
**Latest version:** `1.12.1` — install with `npm i @mocanetwork/airkit@1.12.1`, or omit the version tag to get the latest release from npm. See [Release notes](/api-reference/release-notes) for changes and migration guidance.
</Info>

```bash
npm i @mocanetwork/airkit
```

The package ships in three formats, and your bundler picks the right one automatically:

- `esm` build `dist/airkit.esm.js` is es6 format
- `commonjs` build `dist/airkit.cjs.js` in es5 format
- `umd` build `dist/airkit.umd.min.js` In ES5 format without polyfilling corejs minified

To force a different format, reference its file directly.

## Initialize

AIR Kit creates an iframe that loads the login flow and sets up communication streams between the iframe and the DApp's JavaScript context.

```js
import { AirService, BUILD_ENV } from "@mocanetwork/airkit";

const airService = new AirService({
  partnerId: YOUR_PARTNER_ID // Replace with your actual Partner ID
});
await airService.init({
  buildEnv: BUILD_ENV.SANDBOX,
  enableLogging: true,
  preloadWallet: true, // Optional: Enable if wallet features will be used
  preloadCredential: true, // Optional: Enable if credential features will be used
  sessionConfig: {
    locale: "en", // Optional: Enforce a locale; omit for automatic language selection
    currency: "USD" // Optional: Display currency (e.g. "EUR", "USD", ...)
  }
});

// Without any parameters, this will trigger the default Air login dialog which provides different login methods for the user to choose from.
await airService.login();
```

Once `AirService` is initialized, you can use it to authenticate users. See [User login & sessions](/get-started/user-authentication).

AIR Kit bundles `en`, `ja`, `ko`, `tr`, and `vi`. To customize copy or add languages, use hosted JSON in partner configuration. See [Language & currency configuration](/get-started/config-language).

## Install

The Flutter package is hosted on OnePub, a private package repository. We will provide you with the OnePub login credentials.

```bash
dart pub global activate onepub
onepub login
onepub pub add airkit
```

Then configure each platform for passkeys and app allowlisting:

1. [Flutter installation](/get-started/flutter/installation): OnePub setup, `pubspec.yaml`, and import
2. [Android setup](/get-started/flutter/android-setup): asset statements, SHA-256 fingerprint, `compileSdk` 34+, `minSdk` 26+
3. [iOS setup](/get-started/flutter/ios-setup): associated domains, Apple App ID, iOS 14.0+

<Note>
  For production mobile apps, keep the production AIR domain (`account.air3.com`) in your Android asset statements and iOS associated domains. Use `account.sandbox.air3.com` for Sandbox testing.
</Note>

## Initialize

Create an `AirService` instance and call `initialize`:

```dart
Future<void> initialize({
    required String partnerId,
    required GlobalKey<NavigatorState> navigatorKey,
    Environment env = Environment.production,
    bool enableLogging = false,
})
```

You receive your `partnerId` from us. The `navigatorKey` is used to overlay the dialogs that specific user flows need. During development, use `Environment.sandbox` and enable logging.

```dart
final navigatorKey = GlobalKey<NavigatorState>();
final airService = AirService();

await airService.initialize(
  partnerId: 'YOUR_PARTNER_ID',
  navigatorKey: navigatorKey,
  env: Environment.sandbox,
  enableLogging: true,
);

// In MaterialApp: navigatorKey: navigatorKey
```

See the [Flutter SDK overview](/get-started/flutter/overview) for wallet operations, provider functions, and UI components.
