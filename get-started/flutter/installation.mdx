## Prerequisites

- Flutter SDK and Dart toolchain on your PATH
- OnePub access (credentials provided by Moca)
- Android: `compileSdk` 34+, `minSdk` 26+ (see [Android setup](/get-started/flutter/android-setup))
- iOS: platform 14.0+ in `Podfile` (see [iOS setup](/get-started/flutter/ios-setup))

<Note>
  Production mobile apps should use the production AIR pages and domains, including `account.air3.com` for passkey setup. Moca Chain mainnet is live; see [Production mainnet access](/get-started/environments#production-mainnet-access).
</Note>

## OnePub CLI

```bash
dart pub global activate onepub
onepub login
```

<Warning>
If `onepub` is not found, add Pub’s global bin directory to your PATH, for example: `export PATH=$PATH:$HOME/.pub-cache/bin`
</Warning>

## Add the dependency

**Option A — `pubspec.yaml`**

```yaml
dependencies:
  airkit:
    hosted: https://onepub.dev/api/sxhddavuhn/
    version: ^1.6.0
```

Use the version your team recommends; check [Release notes](/api-reference/release-notes) for current Flutter SDK versions.

**Option B — CLI**

```bash
onepub pub add airkit
```

Then run:

```bash
flutter pub get
```

## Import

```dart
import 'package:airkit/airkit.dart';
```
