Moca Network maintains a public status page where you can check the real-time operational status of its services and view historical uptime data.

## Access the status page

Visit [mocachain.statuspage.io](https://mocachain.statuspage.io) to view the current status of Moca Network services.

The status page displays the operational status of:

* **Moca Network Mainnet** - Mainnet Chain and services status
* **Moca Network Testnet** - Testnet Chain and services status
