Moca Network maintains a public status page where you can check the real-time operational status of Moca Chain services and view historical uptime data. A dedicated AIR status page is on the way — this page will be updated to link it as soon as it's live.

## Moca Chain status

Visit [mocachain.statuspage.io](https://mocachain.statuspage.io) to view the current status of Moca Chain services.

The status page displays the operational status of:

* **Moca Network Mainnet** — Mainnet Chain and services status
* **Moca Network Testnet** — Testnet Chain and services status

* Retry with exponential backoff — see [Rate limiting](/airkit/troubleshooting/common-issues#rate-limiting).
