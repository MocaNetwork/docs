A schema record registers your credential type with AIR so issuance and verification programs can reference it. You register a credential-type identifier (`vct`) and can optionally provide Type Metadata JSON (`vctJson`). The actual credential claims and selective-disclosure behavior are defined in your issuer backend.

<Note>
  To issue Iden3 credentials, contact the AIR team to enable Iden3 for your account: [Partner with us](https://air3.com/partner-with-us). Once enabled, create Iden3 schemas with the [Iden3 Schema Builder](/products/identity/iden3/schema-builder).
</Note>

## Register a credential type

1. Open **Issuer → Schemas** in the Dashboard for your target environment.
2. Enter a descriptive title, description, and credential-type identifier (`vct`).
3. Optionally provide Type Metadata JSON (`vctJson`) describing the credential type and its claims.
4. Publish the record and save its schema ID.
5. Use that schema record when creating your issuance program.

The schema ID identifies the AIR Dashboard record. The `vct` identifies the credential type inside the signed SD-JWT. Do not assume they are interchangeable.

Providing `vctJson` does not configure the credential's claim values or selective-disclosure behavior. Those are supplied by your issuer backend. See [Issuing your first credential](/get-started/quickstarts/issue-credentials) for a backend example.
